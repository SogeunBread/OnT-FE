### 프로필 후속 수정 (2026-11-23)

- 수업 위치 등록의 헤더 아래 구분선을 제거했다. HeaderDetail에 기본값 true인 showBorder 옵션을 추가하고 해당 화면만 false로 설정해 다른 사용처의 기본 구분선을 유지한다.
- 경력 시작일은 오늘 이전, 종료일은 오늘 이하만 추가할 수 있다. 기존 날짜 유효성·기간 역순 검사와 종료일 생략(현재 재직)은 유지한다.
- 종료일이 오늘인 경력은 수정 중 카드와 저장된 프로필 모두 '현재'로 표시한다. 실제 종료일은 보존하므로 다음 날부터는 종료 월로 표시된다. 날짜 비교는 기기 로컬 날짜 기준이다.
- 실제 트레이너 프로필 탭에 목업 리뷰 8개와 해당 평점/리뷰 수를 연결했다. 프로필의 평점을 눌러 리뷰 목록에 진입할 수 있다. 초기 빈 상태 미리보기와 Figma 완성 예시는 별도로 유지한다.
- 검증: 웹 export, 날짜 경계/표시 11개 검사, 브라우저의 시작일 오늘·미래/종료일 미래 버튼 비활성화, 종료일 오늘 추가와 수정·저장 카드의 현재 표시, 리뷰 8개 진입, 위치 헤더 0px/수정 헤더 1px 구분선, git diff --check를 확인했다.
